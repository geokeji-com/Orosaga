# 在线课程左侧括弧样式检查与优化清单

## 1. 检查结论

- 检查日期：2026-08-03
- 检查范围：在线课程学习页中的故事、错误路线、移山做法、底层原理、模型、练习与反馈模块

## 2. 问题定位

内容卡片原来使用 4px 彩色左边框，并与 10px 卡片圆角相连。连续卡片排列时，左边框上下两端形成圆钩，视觉上接近独立的左括弧。

问题集中在课程专属样式 `.course-learning-section` 及其四种语义状态：

1. 项目现场：`tone-neutral`
2. 错误路线：`tone-danger`
3. 移山做法：`tone-success`
4. 底层原理：`tone-principle`
