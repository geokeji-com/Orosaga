# 在线课程可视化结构模型 Review 与修复清单

> 日期：2026-08-03
> 范围：GEO 实战训练营 20 个小节的可视化 HTML 结构模型
> 状态：逐节检查、修复和验证已完成

## 1. Review 结论

本轮采用“企业学习白板”作为统一视觉方向。每一节由模型分类、模型标题、读图提示、结构节点和“带走一句”组成，学员在固定学习画布内完成快速读图。课程继续使用 Orosaga 现有课程蓝、柔和语义色、圆角边界和原生 HTML 语义，不增加新的图表依赖。

20 个模型的平均评分从 **81.5 分提升到 95.9 分**。本轮发现的内容缺口、结构关系、文案一致性、图形遮挡、平板换行、窄屏语义、稳定标识和验证门禁均已处理。当前没有阻塞上线的遗留项。

### Review 范围

- 内容：模型是否覆盖本节核心判断、移山方法和业务动作。
- 结构：图形关系是否匹配流程、层级、矩阵、网络、闭环或协同含义。
- 文案：标题、节点名称、节点说明、读图提示和模型结论是否清楚一致。
- UI：对齐、留白、连接线、色彩层级、节点尺寸和视觉重心是否稳定。
- 跨屏与可用性：1280、768、600、375、320 px 下是否可读，语义和阅读顺序是否成立。

## 5. 内容和设计基线

后续替换课程内容时遵守以下规则：

1. 保留每种布局的固定节点数量。节点增减需要同时调整布局协议和浏览器验证。
2. 节点标识使用稳定业务语义，例如 `search-trigger`。只调整显示顺序时保持标识不变。
3. 模型标题控制在 40 字内，节点名称控制在 16 字内，节点说明控制在 60 字内，模型结论控制在 120 字内。
4. 流程类模型使用顺序线。矩阵、网络、重叠、指标树、实验、闭环和工作台依靠分组、坐标、位置和读图提示表达关系。
5. 节点文案优先写业务对象和可复核动作，减少抽象口号。模型结论需要可以独立复述。
6. 颜色只用于区分角色和状态，课程蓝保留给主路径与当前学习动作。
