## 复核结论

本轮共记录 30 项问题和缺口，其中 29 项已经写回两份方案，1 项等待业务负责人提供正式资料。已完成项包括视觉复刻基线、设计令牌、练习反馈、学习完成规则、API 边界、数据安全、50 题能力映射、课程负荷、系统操作路径、综合评分和来源路由。

等待确认的事项是“百脉达”的正式文档身份。V2.0 已创建 `BAIMAIDA-PENDING` 来源键，在资料确认前不使用该来源支撑课程事实或练习答案。

## V1 与 V2 的关键对比

| 维度       | V1                             | V2                                             |
| ---------- | ------------------------------ | ---------------------------------------------- |
| 视觉复刻   | 有布局规格，缺少截图校准方法   | 6 个固定场景、比例栏宽、叠加校准和允许偏差     |
| 设计系统   | 新建课程令牌和字体栈           | 复用 Orosaga 基础令牌，课程只补充局部状态      |
| 错题反馈   | 提示、解析和重答关系含混       | 完整解析后做纠正确认，答对再继续               |
| 完成规则   | 时间停留和节点点击参与强制解锁 | 用实际任务和等价文字路径判定完成               |
| 数据能力   | 单一步骤数据结构               | 课程、练习、成果物、进度、版本和服务端判定闭环 |
| 题库映射   | 编号齐全，部分主题错位         | 50 个编号逐一校正，五个维度各 10 个            |
| 课程负荷   | 成果物规模和总时长不明确       | 必修 6 至 7 小时，每节只做训练尺寸片段         |
| 业务连接   | 工作流在后 8 节体现            | 增加 Orosaga 系统路径、术语表和小节来源路由    |
| 结业判断   | 五维 80%，评分机制模糊         | 100 分确定性评分、分维度底线和治理关键项       |
| 知识库边界 | “百脉达”以文字备注待确认       | 独立待确认来源键，未确认前禁止发布使用         |
