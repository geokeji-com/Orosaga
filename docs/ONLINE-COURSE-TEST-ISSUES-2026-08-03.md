## CRS-001 修复分解

- [ ] 确认课程实现所在分支和目标环境，记录提交短哈希。
- [ ] 新增 `packages/contracts/src/course.ts`，定义课程、步骤、练习、进度、成果物、评价和证书协议。
- [ ] 增加课程数据库模型和增量迁移，建立课程版本、注册、进度、作答、成果物、评价和证书关系。
- [ ] 注册 `CourseModule`，实现课程目录、课程详情、注册、步骤完成、练习提交、成果物、结业、评价和证书接口。
- [ ] 增加“学习中心”入口和 `/courses` 页面。
- [ ] 增加课程介绍、学习工作台、章节总结、综合实战、结业和证书页面。
- [ ] 导入经过复核的 `PILOT` 课程包，确认试学范围和无证书提示。
- [ ] 使用员工测试账号确认 `/api/v1/courses` 返回 200，且课程卡显示正确版本与进度。

验收标准：登录员工可以从首页进入“学习中心”，打开“GEO 实战训练营”，开始首个开放小节，刷新后仍回到正确步骤。匿名请求课程 API 返回 401，登录员工请求返回 200。

## 完整课程回归清单

这一组项目需要在 CRS-001 完成后执行。当前状态统一为“阻断”。

### 入口与欢迎

- [ ] 飞书登录后进入 Orosaga 首页，身份和欢迎语正确。
- [ ] 顶部导航显示“学习中心”，移动菜单同步显示。
- [ ] 首页新手任务显示课程状态和正确按钮。
- [ ] 首次、学习中、已结业三种招呼语和继续位置正确。

### 课程与进度

- [ ] 课程介绍展示 5 章、20 节、预计时长、版本和学习规则。
- [ ] 首次开始创建一次注册，重复点击不会创建重复记录。
- [ ] 左侧大纲正确显示完成、当前、锁定和补学状态。
- [ ] 第 1 至 20 节依次完成，跳过锁定小节会得到明确提示。
- [ ] 刷新、退出后重进和网络重试均恢复到正确步骤。

### 内容与练习

- [ ] 背景故事、错误做法、移山做法、底层原理、模型图和练习顺序正确。
- [ ] 模型图支持鼠标、键盘和触屏操作，静态说明可独立理解。
- [ ] 错误答案显示选项级提示和详细解析，不开放下一步。
- [ ] 正确答案显示选项级反馈和详细解析，开放下一步。
- [ ] 练习答案由服务端判定，公开响应不含答案键。
- [ ] 成果物自动保存、失败重试和版本冲突处理清楚。

### 挑战、结业与证书

- [ ] 前四章挑战按规则解锁并计算结果。
- [ ] 第 20 节综合实战按总分、维度和治理关键项判定。
- [ ] 结业页显示章节掌握、成果物、补学建议和正式测评资格。
- [ ] 课程评价可以跳过，也可以保存和更新。
- [ ] `PILOT` 版本持续显示不签发证书的提示。
- [ ] 合格 `RELEASE` 版本签发本人证书，撤销记录与打印规则正确。

### 体验与稳定性

- [ ] 桌面双栏布局与参考稿关键比例一致。
- [ ] 平板和手机没有横向溢出，底部操作不会遮挡正文。
- [ ] 键盘可以完成目录、模型、练习、反馈和证书操作。
- [ ] 保存中、保存成功、保存失败和离线状态都有清楚反馈。
- [ ] 401、403、404、409、422 和 503 页面提供可执行的返回路径。
- [ ] 课程内容、进度、评价和证书均通过本人所有权校验。

## 关闭条件

CRS-001 至 CRS-003 全部关闭后，使用一个全新员工测试账号完成 20 节端到端测试。测试报告需要记录每节结果、至少一次答错纠正、一次进度恢复、四次章节挑战、一次综合实战、一次评价和一次证书检查。没有 `RELEASE` 版本时，证书检查以“明确不签发”作为预期结果。
